# Controle de Reembolsos

Monorepo inicial para o desafio fullstack de controle de solicitações de reembolso.

## Estrutura

- `backend`: API Node.js, Express, TypeScript, Prisma, SQLite, Zod, JWT, bcrypt, Jest e Supertest.
- `frontend`: Vite, React, TypeScript, React Router, Context API, Axios e Chakra UI.

## Scripts principais

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm test
```

## Variáveis de ambiente

Copie os arquivos de exemplo antes de rodar localmente:

```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```
